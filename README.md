# SCaD Residencial

Primera arquitectura visual de la PWA para residentes de fraccionamientos residenciales bajo el modelo SCaD.

## Módulos de la APP

- Mensajería
- Orientación
- Documentación
- Programación
- Reportes
- Visitantes

## Panel

Administración corresponde al Panel de gestión y no se presenta como módulo funcional dentro de la APP del residente.
